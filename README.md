**Theory and Practice of Family Therapy and Counseling (2009)**  
Tác giả: **James Robert Bitter, Ed.D.** (East Tennessee State University)  
Lời tựa: **Gerald Corey, Ed.D.**

## ✨ Tính năng nổi bật
- **Giao diện đọc sách chuyên sâu**: Tùy biến font chữ Serif Merriweather, tùy chỉnh cỡ chữ (A- / A+).
- **Bộ lọc giao diện**: Sáng (Light), Giấy cũ (Sepia), Tối (Dark mode).
- **Mục lục điều hướng linh hoạt**: Thanh trượt sidebar tra cứu nhanh từng phân đoạn.
- **Khung ca lâm sàng chuyên biệt**: Minh họa ca điều trị thực tế (Gia đình Quest / Quest Family) qua các trường phái khác nhau.
- **Chuẩn hóa thuật ngữ tâm lý học gia đình**: Thống nhất các thuật ngữ chuyên ngành (biệt hóa bản thân, tam giác hóa, ranh giới, phả hệ genogram, v.v.).
